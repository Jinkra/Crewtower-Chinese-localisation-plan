# CrewTower 简体中文汉化方案

适用版本：CrewTower 1.0.33（构建 427）。本方案提供简体中文语言包，不包含应用程序、第三方框架、许可证或用户会话数据。

## 已完成

补充设置、刘海面板、会话操作、隐私、声音、用量、集成、许可证、插件安装及首次引导的翻译。语言包通过 `plutil -lint` 语法检查。没有修改应用可执行文件。

## 安装与恢复

1. 退出 CrewTower，先将整个 CrewTower.app 复制到安全位置作为备份。
2. 将本仓库的 `zh-Hans.lproj` 复制到应用的 `Contents/Resources/` 中，保留或备份已有语言包。
3. 确认 `Contents/Info.plist` 的 `CFBundleLocalizations` 包含 `zh-Hans`。本次测试对象的开发语言已设为 `zh-Hans`；其他语言需求应保留。
4. 重启应用并逐项验证。若出现启动或签名问题，使用完整应用备份恢复。应用更新可能覆盖此语言包。

修改应用资源可能影响代码签名，语法检查不代表应用启动与显示验证通过。

## 已知限制

- 仅对使用对应本地化键的界面生效。硬编码字符串和运行时拼接内容需要应用源码配合修改。
- 动态状态、缓存倒计时、部分错误说明尚未完整覆盖。

## 完整验收清单

- 刘海面板：展开、收起、空会话、活跃会话、隐藏会话、工具详情及上下文详情。
- 会话状态：思考、运行、空闲、提问、授权、自动批准、压缩、完成、中断及错误。
- 按钮与菜单：发送、停止、批准、拒绝、会话跳转、右键菜单及状态栏菜单。
- 弹窗：权限、插件安装、卸载、许可证、更新及错误提示。
- 全部设置：通用、显示、伙伴、声音、用量、隐私、集成、筛选及许可证。
- 动态数字、日期、插值文本、长文案换行、截断及英文回退。
